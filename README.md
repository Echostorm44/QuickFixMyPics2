This is the second version of Quick Fix My Pics.  This one uses my own C# UI framework CascadeUI and also my own image library that is written in pure C#, no imported or called C or c++ dlls or shelling executables, all pure AOT compatible C# that runs just as fast and often faster than its forebears.  It opens fast and does its job. Need to change that png into a jpg? done. That bmp into an icon?  Batch change that folder into webPs? 
It can also resize images if you need to shrink or grow something.  This isn't a photoshop or even paint.net replacement, sometimes opening one of those apps is more than I need for a quick operation and that is the point of it, a quick fix.
